# Scalping alerts (alert only)

Sends plain-language Telegram alerts for a candidate Bank Nifty trap-reversal idea. It never places orders.
The idea is NOT proven; every message says so. No keys are stored here (GitHub Actions secrets only).

## nr7-alert (added 2026-11-12)
Weekly-ish "narrow day" note for Bank Nifty: after the close, if the day was the quietest of the last 7, a Telegram message gives the next-day break levels. Alert only; candidate rule from a pre-registered 15-year daily test (not proven; weaker since 2025). Silent on other days and on holidays.
